# js/builtin/reflection

Installs reflection (ECMA-262 §28): Reflect and Proxy. The Proxy exotic object itself is js/object's ProxyObject.

```vertex
import "js/builtin/reflection"
```

## Functions

- `func Install(_ r: object.Realm)`: Install defines Reflect and Proxy.

Part of the [`js`](https://github.com/vertex-language/js) repository.
