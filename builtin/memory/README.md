# js/builtin/memory

Installs managing memory (ECMA-262 §26): WeakRef and FinalizationRegistry.

```vertex
import "js/builtin/memory"
```

## Types

- **`WeakRef`** (class)
- **`FinalizationRegistry`** (class)

## Functions

- `func Install(_ r: object.Realm)`: Install defines WeakRef and FinalizationRegistry.
